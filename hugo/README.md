# Hugo Framework

Hugo — это генератор статических сайтов, написанный на языке Go. Он позволяет быстро создавать сайты, генерируя готовые HTML-страницы из шаблонов и контента (обычно написанного в Markdown). Это особенно удобно для блогов, документации, портфолио и других проектов, где не нужен полноценный backend. ⚡ Очень высокая скорость генерации даже больших сайтов.

## Установка и запуск

Официальная инструкция по установке для Windows, macOS и других платформ находится здесь: [gohugo.io/installation/](https://gohugo.io/installation/).

### Установка на Windows

- Простой способ - через Winget (устанавливать не нужно), запустить в powershell:
```powershell
winget install Hugo.Hugo.Extended
```

### Установка на macOS

- Простой способ — через Homebrew:
```sh
brew install hugo
```

### Запуск локального сервера

Для запуска локального сервера с черновиками и отключением быстрой перерисовки используйте команду:

```sh
hugo server --buildDrafts --disableFastRender
```
или
```sh
docker compose up
```

После запуска сайт будет доступен по адресу, указанному в терминале (http://localhost:1313/). Изменения на сайте появляются моментально, без перезагрузки окна браузера.

## Конфигурация

- Основные настройки находятся в файле `hugo.yaml`
- Наполнение сайта и структура находятся в директории `content`
