## Стратегии / Strategies

Стратегии позволяют изменять удалённо некоторые параметры. В текущей стандартной стратегии применено отключение всплывающего окна при подключении пользователя к устройству в правом верхнем углу `Hide connection management window`.

Существует четыре типа настроек:

* Настройки переопределения в веб-консоли → Пользовательские клиенты
* Настройки по умолчанию — в веб-консоли → Пользовательские клиенты
* Пользовательские настройки — в клиенте RustDesk
* Настройки стратегии — в веб-консоли → Стратегии

Иерархия приоритетов этих настроек следующая:
Переопределение > Стратегия > Пользователь > По умолчанию.

[Документация](https://rustdesk.com/docs/en/self-host/rustdesk-server-pro/strategy/)

## Пользовательские клиенты / Custom clients

Страница для генерации различных клиентов rustdesk и хардкодить параметры внутрь них. Внутрь клиент-им и клиент-цуп зашиваются параметры описанные на основной странице, включая пароль, но даже зная пароль прямое подключение минуя аутентификацию bouncer выключено. Собранный клиент доступен для скачивания 5 дней, после требуется перезапустить сборку. Сборка происходит на серверах rustdesk предположительно на гитхаб экшенах, а так же подписывается валидной подписью от самого rustdesk. Обилие параметров для кастомизации доступно на оф.сайте

[Документация](https://rustdesk.com/docs/en/self-host/client-configuration/advanced-settings/)
