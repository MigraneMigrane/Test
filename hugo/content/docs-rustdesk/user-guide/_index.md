Клиент который ставится на управлющие машины отличается от оригинального. Можно использовать оригинальный, но большинство настроек для удобства будут отсутствовать и потребуют ручной настройки. Перечень настроек:

|   Настройка | Параметр  |
|--------|------|
|  Настроено сетевое подключение на наши сервера | -   |
|  Разрешены только исходящие подключения (к вашему ЦУПу/ПК не подключится) | - |
|  Выключена аудио передача | disable-audio=Y   |
|  Выключены принтеры | enable-remote-printer=N |
|  Выключены камеры  | enable-camera=N |
|  Разрешено копирование-вставка | enable-file-copy-paste=Y |
|  Показывать монитор качества соединения | show-quality-monitor=Y |
|  Кодек видеопотока vp9  | codec-preference=vp9 |
|  Открывать новые подключения в отдельном окне | enable-open-new-connections-in-tabs=N |
|  Динамическое разрешение  | view-style=adaptive |
|  Пароль по умолчанию  | default-connect-password=***, verification-method=use-permanent-password,approve-mode=password  |
|  Скрыть предупреждение о пароле | remove-preset-password-warning=Y |
|  Выключить LAN discovery  | enable-lan-discovery=N  |
